Deployment

Deploy in 60 Seconds

Requires Windows PC with PHP 8.3 and MariaDB 11.x running on port 3306.

1. Clone & Install Database:

git clone https://github.com/it1buildhub-hue/SANAM.git
cd SANAM
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\install.ps1

2. Start the Local Server:

powershell -NoProfile -ExecutionPolicy Bypass -File scripts\start.ps1

Open http://127.0.0.1:8081 in your browser. (Or use -Demo for sample data on port 8083).
